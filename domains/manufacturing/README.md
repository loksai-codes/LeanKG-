# manufacturing domain pack

Machines, components, failure modes, causes, maintenance actions and Toyota Production
System (TPS) concepts, in English and Japanese.

**Data status:** dictionary rows, patterns and fixture sentences are **hand-written seed
data** by the leankg authors unless a file says otherwise. Public datasets (NHTSA, MaintIE,
Japanese Wikipedia) are fetched by download scripts and are never committed; see `DATA.md`.

Layout is the same as every pack: `ontology.yaml`, `dictionaries/`, `patterns/`,
`models.yaml`, `llm_hints*.md`, `eval/`.
